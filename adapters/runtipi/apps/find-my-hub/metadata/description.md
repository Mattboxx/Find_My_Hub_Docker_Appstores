# Find My Hub

One self-hosted map for your Apple Find My and Google Find Hub trackers, with
local history, persistent time ranges, isolated user accounts and reversible
multi-tracker views. Optional MQTT/Home Assistant and Traccar map outputs do not
replace the built-in map or make external integrations mandatory.

Includes identity generation/guarded rotation, user administration, selective
export, complete web backups, ESP32/Nordic programming and an optimized configured
ESP32 advertising library. See the guides for provider onboarding and limitations.

Unofficial integrations, not GPS or guaranteed real-time tracking. Use accounts
and devices you own. Screenshots use synthetic data. Provider login volumes
need separate backups; personalized firmware ZIPs and keys must remain private.
